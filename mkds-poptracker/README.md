# Mario Kart DS PopTracker pack

A simple, functional PopTracker pack for the Mario Kart DS Archipelago world - no custom
art, single-color programmatically-generated icons. Auto-tracks over a live Archipelago
connection (no game-memory reading on PopTracker's side - it listens to the same
item/location stream the BizHawk client itself uses).

## Install

Drop this whole `mkds-poptracker` folder (or the zipped copy) into PopTracker's `packs/`
directory, then select "Mario Kart DS" when connecting to your session.

## Layout

Everything is on one continuously-scrollable page (no tabs), top to bottom:
Characters / Karts / Cups / Time Trial / Missions.

## Visual states

- **Characters, Karts** - simple two-state: greyed out (not yet unlocked) vs. fully
  colored (unlocked). No "completion" concept - you don't complete a character or a
  kart. All 36 real karts are individually tracked (not just one shared "Standard Kart"
  slot) - each works for any character, matching the base game.
- **Cups, Time Trial tracks, Missions** - three states, since each of these has both an
  *unlock* (its own AP item received) and a *completion* (its "- Win"/"- Staff Ghost
  Beaten"/"- Clear" location checked):
  1. Locked (not yet unlocked) - the default grey icon.
  2. Unlocked, not completed - green icon.
  3. Unlocked and completed - grey icon (same grey tone as the base "locked" icon, but
     only reachable *after* passing through green - the two greys are never ambiguous in
     context since a fresh seed starts everything at stage 1's own locked look, not this
     one).
- Each seed's one free starting character/kart/cup/track/mission (position 0 - see the
  world's own README/NOTES.md) is marked unlocked automatically on connect, since
  position 0 never generates its own AP item event. Already-completed locations are also
  correctly resynced to grey after a reconnect (via `Archipelago.CheckedLocations`, added
  in PopTracker 0.25.2 - see `min_poptracker_version` in `manifest.json`).

## Regenerating

`items/items.json`, `layouts/layouts.json`, and every `scripts/*_to_code.lua` lookup
table are generated by `generate_pack.py`, directly from `worlds/mkds`'s own
`items.py`/`locations.py`/`rom_addresses.py` - they should never be hand-edited (a real
bug in an earlier version of this pack came from exactly that: a hand-maintained lookup
table drifted from the real AP item names). Re-run after any change to the world's
item/location names:

```
py generate_pack.py [path-to-Archipelago-checkout]
```

Defaults to `../reference/Archipelago` (this project's local dev checkout) if no path is
given. Images (`images/*.png`), `scripts/init.lua`, `scripts/autotracking.lua`,
`manifest.json`, and this README are hand-written and untouched by the generator.

## Status

doesn't render or track as expected, that's the most likely reason; please report back
